# Product Roadmap

### Goal

Create the technical foundation of the platform.

### Deliverables

- Angular Frontend
- FastAPI Backend
- Ollama Integration
- Llama 3.2 Integration
- Docker Environment
- Basic Chat Interface

### Goal

Create a functional conversational agent.

### Deliverables

- Conversation Management
- Prompt Templates
- Session Handling
- Chat History

- SQL Generation

- Result Interpretation
- Analytics Responses
